# Movies.Api.Sdk.Consumer

Este é um projeto de exemplo que demonstra como consumir o SDK da API de filmes. Ele serve como referência para qualquer aplicação cliente que queira interagir com a API de filmes.

## Estrutura do Projeto

- **AuthTokenProvider.cs** - Classe para obter e gerenciar tokens de autenticação
- **Program.cs** - Aplicação de console que demonstra o uso do SDK

## Funcionalidades Demonstradas

Este projeto demonstra:
- Como configurar o SDK em uma aplicação cliente
- Como autenticar com a API usando JWT
- Como realizar operações CRUD de filmes
- Como gerenciar avaliações de filmes

Este projeto serve como um guia prático para integrar a API de filmes em qualquer aplicação cliente usando o SDK fornecido.
