# Movies.Contracts

Este projeto contém os contratos (DTOs) usados para comunicação entre a API e seus consumidores. Esses objetos são usados tanto para receber solicitações (Requests) quanto para enviar respostas (Responses).

## Estrutura do Projeto

- **Requests/** - Classes que representam dados de entrada para a API
- **Responses/** - Classes que representam dados de saída da API

## Como Usar

Estes contratos são compartilhados entre a API e seus consumidores, garantindo uma comunicação consistente. Para usar:

1. **Na API**: Usados para validar entradas e formatar saídas
2. **No cliente/SDK**: Usados para formar solicitações e interpretar respostas

Este projeto não tem dependências externas e pode ser facilmente compartilhado entre diferentes componentes do sistema.
